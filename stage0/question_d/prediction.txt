Result: it ran faster on O2 than O0, on both Windows and the Pi (e.g. Pi loop 42,902 ns → 81 ns, Pi recursion 114,328 ns → 1,918 ns). However, O3 was not faster than O2 on either platform.

Prediction 2: Windows faster for loop, Pi faster for recursion

Expected: Windows would run the loop faster, while the Pi would run the recursion faster.
Result: The prediction held. Windows was about 2.8× faster for the loop, while the Pi was faster for recursion at every level (2.5× at O0, 16× at O2).

Reason: The loop depends mainly on raw CPU speed, where Windows has the faster processor. Recursion depends on function-call cost, which is cheaper on ARM because it stores the return address in a register instead of on the stack like Windows x64.
